# 鹈鹕逐雪 V5

正式入口：https://yingchuixue333-droid.github.io/pelican-ride/

index.html 直接加载 journey/app.js。旧 game/ 保留历史，非正式入口。

V5沿用原创绘本矢量、持续挑战和单指输入。普通短按即时跳，长按约180ms翻转，松手停转，空中再按一次扑翼；扑翼优先于近地缓冲。一场飞行只有一次扑翼，落地刷新。优质落地约20°，可站住范围约60°，明显倒立才重摔。近整圈渐进计分，保留原始角度，不自动补圈。

平台采用统一 platformY / platformSlope，绘制每8世界单位采样；浮冰首次着陆真实下沉。跳台肩是实际地形，起跳加成随位置平滑变化。高台出口真实下落。六类线路、阶段关系变化、4段主题渐变、限速视野契约、真实路线完成与一次飞行单次倍率。普通主路速度可维持雪崩安全，失误实际丢动量。

本机V5成绩与V4历史隔离，鱼/装束/纪念保留；结算可立即重开、同种子再试、复用失败段真实入口状态练习（不计成长）。教学按真实已学操作收束。

开发：npm test。qa/v5-results.json 是实际正式物理的功能结果；4种子/180秒固定暴露、有限前方观察合成策略（精确碰撞数据比看像素有优势）、一个600秒连续后段检查和六场景释放扫描。机器不是人类试玩者。
