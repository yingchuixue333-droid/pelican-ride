# 风里农场 · 丰收画卷

正式网址：https://yingchuixue333-droid.github.io/pelican-ride/

42种作物，2分钟至16小时；一键打理完成收菜、续种与浇水，田满可预选下一轮。独立永久果园按自然时间成长，6小时开始结果、48小时进入最高自然阶段，果实最多积存4份，换品种保留树龄与培育。

上线时间无需固定。免费萝卜每块12经验，长作每茬经验最高80；小丰收每两次实际采收出现一次，额外金币不影响基础售价。现有作物的已存收益和时间保持原值。V1/V2备份自动迁移至V3，同一网址继续游玩。
