# 鹈鹕逐雪 · 海湾旅程

正式游戏：https://yingchuixue333-droid.github.io/pelican-ride/

版本 `snowbound-3.0.0`。新方案来自用户授权的完整重做提示词，覆盖历史玩法。Canvas 2D 原创分层绘本角色与合成音频，资源全在本站。

## 操作

整个游戏画面轻点立即完整起跳；持续按住180ms后翻转，松手停止；空中松开后再点一次扑翼。每次腾空最多一次扑翼。落地持续按住不会自动连跳。电脑鼠标和空格使用同一状态机。暂停按钮除外。

## 旅程

约3–4分钟：晨光雪谷 → 杉林冰河 → 蓝晶洞穴 → 落日海湾灯塔。低路可以不翻转通关，高路提供可选平台与连招。雪狐提速、雪兔提高起跳、雪团兽提供一次保护；磁铁、风翼、羽毛三种道具。三枚自动救援羽毛、每30鱼补一枚，上限三枚。轻碰自动恢复；无保护的重摔不直接杀死角色。

练习与主模式共享控制和地形；练习不计入主成绩。通关解锁复用式无尽模式，生成组合与速度有上限。六种围巾/板面通过累计鱼、里程、通关解锁，只改外观。存档在本地，保留旧数据的最佳成绩入口。

## 开发与验证

`npm test`：同源物理测试与12固定种子低/高/不操作连续全程策略。`node qa/reaction-window.mjs`：代表性石头和倒木起跳窗口采样。测试结果在 `qa/one-touch-results.json`。`one-touch-review.html`是同源验收入口，仅通过合法输入运行，不改变角色坐标或速度。

素材是项目原有原创矢量分层资产的重做与改造，音频为原创Web Audio合成；没有引入商业游戏美术、音乐或代码。参考设计方法见 `JOURNEY-RELEASE.md`。
