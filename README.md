# 风里农场 · 丰收画卷

正式网址：https://yingchuixue333-droid.github.io/pelican-ride/

40种作物，从2分钟短作到8小时长作；包含多次采收与果树。购买种子、浇水、自动出售、6至12块田、三级土地、一键续种及确认后铲除退款。无仓库/变异/图鉴/任务/装修。

开局可种4小时水稻，2级有苹果树，3级有6小时西瓜；24级全部解锁。一键种收浇水与全部铲除，未收过全退、多茬按剩余比例退。独立新档指定种植策略模拟：每天8次×4分钟约1.34天完成主要解锁；实际因种植选择、频率及旧进度而异。
