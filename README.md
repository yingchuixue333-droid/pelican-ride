# 风里农场 · 丰收季

[打开正式农场](https://yingchuixue333-droid.github.io/pelican-ride/)

- 轻点一块田，下方操作栏可收获、播种、浇水、施肥、改良或换种。点「详情」看准确成熟时间、茬数和收益。底栏按可做的事优先显示「收获」「开闸浇」或「照料」，也保留同一时刻可用的次要操作。
- 水渠右端开闸可浇所有可浇田，和单田浇水共用每茬一次、原时长减 25% 的规则。原始本茬时长至少 60 分钟的未成熟作物可选金币 +5% 或经验 +10%，四舍五入取整，仅本茬一次。底栏「照料」直接预览全田合计增益，选定后只给当时符合条件的田施肥。偶遇小虫点中得 3 经验。
- 全田换种是通用计划，单田可以覆盖并恢复跟随。确认后只对范围内可用的新种空田扣费，田里作物全部收完才换。金币不足保留计划。
- 种子铺本季共有 18 种作物。16、18、21、24、27、30 级增加不同用途的新菜。16 级送一包荷兰豆，第一次收获点亮图鉴。普通升级 25 金币。20 级付费开垦最后两块田、付费改良到 Lv.10。
- 果园七个树位分布在近畦与里畦，点首屏标签即可切换。点空土畦或「种树」即可种植，两块自选树位可种桃、李、梨、柿子或枇杷。点果直接采摘，点树看具体结果时间。首果 15 分钟，随后每小时一颗，48 小时达盛果阶段。
- 右下点编织篮看品种、数量与实际入篮价值，可以单卖或全卖。旧档只有总数量和总价时保留为可独立出售的「旧篮存量」。
- 全田无收获、浇水或照料操作时，底栏显示最早成熟田块和等待时间。空田可以从底栏种免费萝卜。田都满着时可安排一块做短作，当前作物收完所有茬次才换。
- 进度保存在玩这块农场的浏览器中。可以从设置导出和导入 JSON。原站点、旧存档键和正在生长的作物快照继续使用。

开发使用 `npm run dev`，回归使用 `npm test`。接续开发先读 [PROJECT.md](PROJECT.md) 和[丰收季数值与迁移](FARM-RAIN7-RELEASE.md)。
