# 鹈鹕逐雪 · V4

正式入口：https://yingchuixue333-droid.github.io/pelican-ride/

单指全屏滑雪：轻点立即起跳；按住超过180ms持续翻转，松手停转；空中再点一次扑翼，扑翼不清空旋转。大跳台要主动起跳；小丘只适合普通跳。翻转按滑板相对实际落地面的角度评级，普通跳跃不要求技巧姿态。

主模式为持续挑战，没有三分钟自动终点。初次约75秒引导自然进入挑战，首局失败后可跳过引导。练习与每日固定雪路复用同一物理，每日仅本机个人纪录。

分数分距离、10分/鱼收集与技巧，只有有效翻转、高路完成、不同伙伴的主动接力进连招。普通起跳/落地不赠分或雪崩距离。救援羽毛开局2、上限2，仅用于真实坠崖；鱼不补羽毛。雪团兽挡一次重撞，雪狐/雪兔没有共享隐藏盾。

24个主模板、6类路线与恢复段，连接时继承全状态；后段有界增加速度、雪崩压力与组合。四套完整装束使用同一原创矢量角色绑定，保留旧存档；V3旧纪录保留但不混入V4成绩。
